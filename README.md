# Nova — adaptive rhythm

Nova is a polished single-page prototype for a personal AI companion that connects learning, practice, training and recovery in one adaptive daily rhythm.

## Included in the prototype

- Russian-language responsive dashboard with readiness, sleep, load and focus signals
- Adaptive coach card and a personal plan for the day
- Learning library with course progress and a daily practice prompt
- Training plan with readiness recommendation, weekly load, workout history and body signals
- Analytics with interactive 7-day / 30-day readiness chart and generated insights
- Goals, schedule and notes spaces
- Quick log modal for mood and context capture
- Responsive mobile bottom navigation and desktop sidebar

## Run locally

```bash
npm install
npm run dev
```

The dev server binds to `0.0.0.0` for preview environments. Production build:

```bash
npm run build
```
